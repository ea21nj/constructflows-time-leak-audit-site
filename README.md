# ConstructFlows Time-Leak Audit Site

Static marketing site for the ConstructFlows Contractor Time-Leak Audit.

## Pages

- `index.html` — landing page and calculator
- `constructflows-contact.html` — claim offer form
- `constructflows-services-pricing.html` — services/pricing page
- `constructflows-thank-you.html` — form submission confirmation page

## Deployment

This is a static HTML/CSS/JS site and can be deployed directly to Vercel.
